# 豐中常文庫（とよなかとこぶんこ）

中常塾（塾主：松浦茂樹）所蔵・関連書籍のデジタル文庫。
名称は、度會神道家・出口延佳が建立した **豐宮崎文庫** に敬意を表したもの。

> 度會神道の根本古典を、現代の手に ──

## 構成

```
豐中常文庫/
├── index.html              文庫トップ（所蔵書籍一覧）
├── README.md               本ファイル
└── 倭姫命世記/
    ├── index.html          ビューアー（書写本画像／翻刻／解題の三タブ）
    └── images/             書写本画像 45丁（web最適化済・幅2000px・計約23MB）
```

静的HTMLのみ。**ビルド不要・サーバー不要・自己完結**で動作する。

## 第一冊：倭姫命世記（やまとひめのみことせいき）

- **底本**：塾主所蔵『倭姫命世記』書写本（寛文九年・**出口延佳 校合本**／全45丁）
- **内容**：神道五部書の一。倭姫命の遊行と伊勢神宮鎮座、御饌・懸税・神嘗祭の起源を記す度會神道の核心古典
- **三層構成**：
  - 書写本画像（全45丁のページめくり＋サムネイル）
  - 翻刻テキスト（『大神宮叢書 度会神道大成』と校合して精度を高めた確定読み）
  - 解題（書誌・中常塾との縁）
- **校合の成果**（『度会神道大成』との照合で確定）：
  - 伊雜宮造営者 **伊佐波登美神**、**懸税・御神酒の起源**（page_25／大成 p.72-73）
  - **心御柱**＝塾名「中常」の原典（page_30／大成 p.72）
  - **1300年の伝来史**（奥書 page_42-44／大成 p.85-87）
  - 詳細：`context/core/倭姫命世記_大成照合/校異メモ.md`

## WEB公開のしかた

このフォルダは自己完結しているので、**そのまま静的ホスティングに置くだけ**で公開できる。

- **GitHub Pages**：このフォルダをリポジトリへ push し、Settings → Pages で公開ブランチ/フォルダを指定
- **Netlify / Cloudflare Pages**：フォルダをドラッグ＆ドロップ（ビルドコマンド不要）
- **その他**：任意のWebサーバーの公開ディレクトリに配置

> 高精細の元画像（各5MB級）は照合用に `context/core/倭姫命世記_書写本/` に保存。
> 本文庫の `images/` はそれを web 用に軽量化したもの。

## 公開範囲についての注意（重要）

- 公開してよいのは **度會神道の古典そのもの**（倭姫命世記等）に限る
- **中常塾の内部資料（経営戦略・ワクワク系マーケティングの知見・和儀指導者テキスト等）は一切含めない**
- 和儀は「初心講座テキスト（対外可）」のみ。**指導者テキストは収録しない**
