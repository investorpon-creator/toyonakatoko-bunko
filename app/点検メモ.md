# 中常塾アプリ 点検メモ（2026-11-03）

## 1. このアプリは何か・誰がどう使うか

- `/app/` は、ホーム画面に追加して使う PWA「中常塾」。塾生・講義お稽古に来る方・中常だよりの読者が、スマホで開く入口。
- 文章はアプリに持たず、サイトと同じファイルを読む（直すのはサイト側）。
  - `/kotoba.js` … 七十二候ごとの「今日の一節」と「塾主の一言」
  - `/tayori.js` ＋ `/bunko/kaidan/kaidan.js` … 新着のたより（今日より先の日付は出さない）
  - `/events.js` … 開催予定（過ぎた日は自動で消える。`v:` `addr:` が無い回は岡崎城 二の丸能楽堂）
- 画面は1枚の `index.html` を `#top` `#hitokoto` `#tayori` `#kaisai` `#menu` `#access` `#howto` `#privacy` で切り替える（`app.js`）。
- 下のタブ：トップ／一言／たより／LINE（外部）／MENU。お知らせの受け取りは LINE公式に任せている。

## 2. 点検の結果

点検は Playwright（iPhone 13・iPhone SE・Pixel 7 の幅）で `python3 -m http.server` を立てて行った。

| 項目 | 結果 |
|---|---|
| manifest（name・start_url `/app/`・scope `/app/`・id・display standalone・192/512 アイコン） | 満たしている |
| maskable アイコン | **不具合**：角の丸い（角が透明な）`icon-512.png` をそのまま maskable にしていた。Android で丸や角丸に切り抜くと、角に透き間が出て、文字が安全域（中央80%）からはみ出す |
| オフライン | **不具合**：控えに置くのが骨組みだけで、`kotoba.js` `tayori.js` `kaidan.js` `events.js` を入れていなかった。入れてすぐ圏外で開くと中身が空。さらに、控えに無いスクリプトに `index.html` を返していたため、JS として読まれて構文エラーになる |
| サイト更新時に古いままにならないか | ネット優先なので概ね新しくなるが、ブラウザの HTTP の控え（GitHub Pages は約10分）を通るため、直後は古いことがある。404 などの失敗した応答も控えに入れていた。`sw.js` 自体もブラウザの控えを通っていた |
| 版の上げ方・更新の通知 | 版（`VER`）はあるが、入れ替わっても画面に知らせが無い。古い控えの消し方が、同じドメインの他の控えまで消す書き方だった |
| コンソール | アプリ由来のエラーは無し（計測の `gc.zgo.at` は点検環境では外へ出られないため失敗するだけ。本番は https で読む） |
| iOS：apple-touch-icon | 180×180、透明なし。よい |
| iOS：ステータスバー | `black` だと時刻の帯が真っ黒になり、頭の墨色（#272018）と色が合わない。頭はすでに `safe-area-inset-top` を足す作りなので `black-translucent` が合う |
| iOS：セーフエリア | 上と下（タブ）は手当て済み。**横向き**のときの左右（ノッチ側）が手当てされていなかった |
| 小さい画面（幅320px・iPhone SE） | トップの4つのマスで「中常だより」が「中常だよ／り」と折れる |

## 3. 直したこと

- `sw.js`（版 v3 → **v4**）
  - 入れるときに中身の4ファイル・アイコン・favicon も控えに置く（`cache:"reload"` で取り直す）。
  - 画面（ページ）以外は、ネットを先に見るときブラウザの控えを確かめ直す（`cache:"no-cache"`）。
  - 成功した応答だけを控えに入れる。圏外で控えが無いときは、ページなら `/app/` を、スクリプトなどならエラーを返す（HTML を JS として返さない）。
  - 古い控えの削除は `nakatoko-app-` で始まるものに限る。
  - 冒頭のコメントに版の上げ方を書いた：**`sw.js` を書き換えたら `VER` を一つ進める。中身のファイルを直すだけなら上げなくてよい。**
- `app.js`
  - `sw.js` を `updateViaCache:"none"` で登録し、アプリに戻ってくるたびに更新を確かめる。
  - 新しい版に入れ替わったら、下に「新しい版になりました ／ ひらき直す」を出す（初めて入れたときは出さない）。
  - `localhost` でも登録する（点検のため。本番の動きは変わらない）。
- `icons/icon-maskable-512.png` を新しく作り、manifest の maskable をこれに替えた（元の印を72%に縮めて、同じ朱の地に置いた）。
- `index.html`
  - ステータスバーを `black-translucent` に。
  - 横向きのときの左右のセーフエリアを、頭・本文・タブに足した。
  - 幅360px未満でマスの余白と字間を詰めた。
  - MENU の版表示を 1.1 → 1.2。

## 4. 使い勝手の改善（3つ）

1. **次の催しが一目でわかる**：トップの暦の下に「次の催し」の札を置いた。日付・「あと◯日／明日／本日」・会場と住所、ボタン（くわしく／地図／駐車場・アクセス）。
   - 理由：このアプリを開く一番の用事は「次はいつ・どこか」。これまでは小さなマスに日付だけで、会場はもう一度押さないと見えなかった。伊勢の回のように会場が変わるときこそ、最初の画面に会場が出ている必要がある。
2. **地図・駐車場案内へすぐ行ける**：「次回開催」の各回に「地図」「駐車場・アクセス」を足した。地図は、能楽堂の回は会場名で、ほかの会場の回は `events.js` の住所（括弧書きを除く）で Google マップを開く。アクセスの頁には「次回開催を見る」を足した。
   - 理由：駐車場の案内（岡崎公園・りぶら2時間無料、世木神社は駐車場なし）はすでに書かれているのに、MENU の奥にあって当日に探しにくかった。新しい事実は足さず、既にある案内へ道をつけただけ。
3. **新しいたよりの印**：前に「たより」を開いた日より後のたよりに「新」、たよりのタブに朱の点を付ける。開けば消える（端末の localStorage に日付を一つ置くだけ。使えない端末では印が出ないだけで、ほかは変わらない）。初めての方には、この14日以内のたよりに付ける。
   - 理由：たよりは月に何度か増えるが、増えたかどうかが外から見えなかった。通知は LINE に任せたまま、アプリ側では「開いたときに気づける」ことに留めた。

選ばなかったもの：**文字の大きさの切り替え**。字の大きさは rem で組まれていて、端末の拡大でも読める。ボタンを足すとトップや MENU が増え、上の3つほど困りごとがはっきりしていないので、今回は見送った。

## 5. 確かめたこと

- 作業の前後で、トップ・次回開催・たより・一言・MENU・アクセスのスクリーンショットを比べた。違いが出たのは手を入れたところ（トップの札、各回のボタン、MENU の版表示、アクセスのボタン）だけで、たより・一言は画素単位で同じ。スクリーンショットはコミットしていない。
- 入れたあと圏外にして開き直し、一節・たより・次回開催が出ることを確かめた。
- `VER` を一つ進めると、古い控えが消え、「新しい版になりました」が出ることを確かめた（確かめたあと v4 に戻した）。
- 日付を 2026-10-31 にして、伊勢の回が「明日」と出て、地図が伊勢の住所で開くことを確かめた。
- `events.js` ほか、`app/` の外のファイルは変えていない。

## 6. 残したこと（今回は触れない）

- Google Fonts は別のドメインなので圏外では控えに入らず、圏外ではしっぽり明朝の代わりに端末の明朝で出る。
- `app.js` の七十二候の表は、トップの `index.html` と二重に持っている（コメントのとおり、暦を直すときは両方を揃える）。
